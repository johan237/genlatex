# Cursor Prompt Pack for GenLaTeX Blog Articles

## 🎯 Standard Blog Prompt

Write a long-form SEO blog article following the GenLaTeX Blog Writing Instructions.

Main keyword: [INSERT MAIN KEYWORD]  
Secondary keywords: [INSERT 3–5 KEYWORDS]  
Target audience: students and researchers  
Tone: professional, neutral, educational  
Length: 1500–2000 words  

Include:
- SEO title
- Meta description
- Introduction
- H2 and H3 sections
- Dedicated GenLaTeX section
- Comparison with at least 2 competitors
- FAQ section (5–7 questions)
- Conclusion

Avoid:
- hype
- emojis
- unethical claims
- keyword stuffing
